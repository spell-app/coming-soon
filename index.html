Spell

Programs you can read out loud.

You just read a program.
Nobody taught you its syntax, and you could explain it to a friend.

It isn't pseudo-code, and it isn't an AI prompt:

  • a rule-based parser reads Spell the same way every time, and
  • it compiles to optimized, readable code you can run right on the web.

Solitaire in Spell

¡El mismo juego, en español!

All magic, no fuss!

  • A language that reads like English (and Spanish, soon French, German...)
    – types, properties and actions are sentences.
  • A compiler to JavaScript, TypeScript and Python
    – so what you write runs where you need it.
  • An editor where the program, the running app and its output sit side by side.

Spell UI

A full set of beautifully themed web components (<ui-button>, <ui-theme-selector>)
that work in any page, with or without the rest of Spell.

Status

Working now:

  • Spell, the language: English and Spanish, in sentences or outline form.
  • Output to web apps in JavaScript, TypeScript and Python.
  • Spell Editor: interactively write, run, and test a program in one window.
  • Spell UI: powerful, friendly, fully-themed web components for any page.
  • VS Code extension: syntax colouring, errors and help as you type.
  • spell command line tool: compile, run, test and translate projects.
  • AI-written spells via Claude Code in VSCode.

Coming soon:

  • Input: More human languages.
  • Output: More programming output languages.
  • Publish your Spell site on the web.
  • Use AI to write a spell on your computer, tablet or phone.

The first release is on its way, targeting December 2026.
